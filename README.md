# LUMORA — Creative Studio Landing Page

A modern and responsive creative studio landing page built with **HTML5, SCSS, and JavaScript**.

LUMORA was created as a frontend practice and portfolio project with a focus on modern visual design, responsive layouts, organized SCSS styling, and interactive frontend elements.

## Live Demo

[View Live Demo](https://fereshte-rahnama.github.io/lumora-creative-studio-/)

## Technologies Used

* HTML5
* SCSS / Sass
* CSS3
* JavaScript
* Flexbox
* Responsive Design
* Media Queries
* Boxicons

## Features

* Responsive navigation
* Mobile hamburger menu
* Hero section with promotional content
* Animated scrolling text
* Services section
* Selected projects section
* About section
* Call-to-action section
* Responsive footer
* Smooth scrolling navigation
* Hover and transition effects
* Responsive layouts for desktop, tablet, and mobile

## SCSS

The project uses **SCSS/Sass** to organize and maintain the styling code.

The styling makes use of:

* SCSS variables
* Nesting
* Partial files
* Responsive media queries

The project separates the SCSS source from the compiled CSS, making the styling easier to manage and update.

## Responsive Design

LUMORA is designed to adapt to different screen sizes, including:

* Desktop
* Tablet
* Mobile

The navigation switches to a hamburger menu on smaller screens, and the layout of the different sections adapts to smaller viewports.

## JavaScript

JavaScript is used for interactive elements of the page, including the mobile navigation menu and other frontend interactions.

## Design

LUMORA uses a modern creative-studio aesthetic with:

* Dark backgrounds
* Purple accent colors
* Large typography
* Minimal layouts
* Spacious sections
* Smooth transitions
* Modern UI elements

The design focuses on creating a clean and contemporary landing page for a fictional creative studio.

## Project Purpose

The main purpose of this project was to practice and demonstrate:

* SCSS architecture
* Variables 
* SCSS nesting
* Flexbox 
* Responsive web design
* Media queries
* JavaScript interactions
* Modern landing-page development
* Organizing frontend styles in a maintainable way
